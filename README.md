# FST-EAH-EEC-source-code
R Source Code for the Fertility-Sparing Treatment Study

K-M analysis.R

This script performs Kaplan–Meier analysis of the cumulative complete response rate and compares survival curves using the log-rank test. The publicly available script uses histological diagnosis (EAH versus EEC) as an example grouping variable. The same analytical workflow was also used to generate Kaplan–Meier curves for other clinicopathological characteristics included in the manuscript.

Data availability

The individual-level clinical and pathological data are not included in this repository because of patient privacy and institutional ethical restrictions.
